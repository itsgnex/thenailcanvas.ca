# The Nail Canvas Static Showcase

Static visual prototype for The Nail Canvas, built for GitHub Pages.

## Commands

- `npm run build` copies the deployable site into `dist/`
- `npm run serve` starts a local static server for `dist/` at `http://localhost:4173`

## Images

The current images are local Pexels placeholders in `public/images/nails/`.
They are intentionally named with the `placeholder-` prefix so they can be replaced with real The Nail Canvas photos later.
